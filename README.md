# 复航 / RECOVERY ATLAS
## 肺癌术后全周期康复与预后决策支持系统

> **定位**：面向非小细胞肺癌（NSCLC）术后病友、家属及随访医疗团队的轻量化、循证型临床决策与居家康复支持平台。  
> **特性**：全单文件自内聚架构 · 零外部重型依赖 · 纯本地隐私安全 · 适老化设计 · 国际权威指南对齐。

---

### 🌟 系统设计理念

肺癌术后患者在出院回家后，往往面临“**看不懂病理报告、恐慌复发却不知如何应对、复查增强 CT 因未准备而白跑医院、口服靶向药饱受甲沟炎与皮疹折磨**”等真实的就医与生活断层。

本系统旨在打通“院内手术评估”到“院外长期生存”的完整服务链，让专业医疗指南转化为患者及家属**“看得懂、用得上、防得住”**的数字化工具。

---

### 📋 核心功能模块

#### 1. 🏡 适老化居家生活日常指南（13 大高频生活痛点）
* **生活实操全覆盖**：
  * **卧位与睡眠**：半卧位促肺复张、健侧侧卧胸前夹枕泄力、术侧防寒保暖；
  * **切口与洗澡**：出院干燥脱痂后快速淋浴要领、严禁盆浴搓洗、肉芽新生发痒防护；
  * **家务与活动**：厨房高温油烟禁忌、术侧手臂限重 3kg、防范“凝肩”手指爬墙操；
  * **出行与旅游**：气压变化防气胸（术后 4~6 周胸片无漏气方可乘机）、高原低氧规避；
  * **心态与情绪**：扫描焦虑（Scanxiety）科学调试、视复查为排雷盾牌；
  * **常规用药安全**：固定服药时间、漏服补服黄金 12 小时原则、抑酸胃药错开 2~4 小时；
  * **气道排痰保护**：喉返神经水肿声嘶恢复、温水压制干咳、“双手抱枕爆发性排痰法”抵消 90% 震动牵拉痛；
  * **排便安全红线**：严禁闭气死命排便（瓦氏动作防残端瘘与气胸）、温水西梅汁与乳果糖通便；
  * **衣着防神经痛**：前开襟纯棉开衫、女性术后半年内坚决远离钢圈定型文胸；
  * **科学体能重建**：八段锦/太极拳首选、谈话测试把控运动强度、血氧饱和度 <90% 悬崖红线；
  * **居家环境安全**：雾霾天（AQI>100）停止晨练、彻底清除二手与三手烟、坚决禁点明火蚊香与拜佛燃香、空气净化器选 HEPA 坚决避开臭氧电离机型；
  * **靶向药副作用居家自救**：甲沟炎温水加碘伏浸泡外涂百多邦、面部痤疮样皮疹温水清洁防晒、口腔溃疡温生理盐水含漱软食、轻度腹泻白粥补盐水防脱水。
* **国际循证专区**：实时检索对照 NCCN 2025、CSCO 2025、ESMO 2024 等前沿诊疗共识。

#### 2. 🚨 急危重症红黄绿灯自查与语音带练
* **三级分诊预警**：
  * **红色警报（立即急诊）**：突发大咯血、剧烈胸痛大汗严重憋气、高热 >38.5℃、单侧小腿肿痛（下肢深静脉血栓）；
  * **黄色警戒（1~3日就诊）**：腹泻每日 >3 次、皮疹破溃、进行性刺激性干咳；
  * **绿色安心（居家静养）**：术侧肋间神经麻木刺痛、咳陈旧暗褐血丝、平地慢走轻度气促。
* **原生适老语音朗读引擎**：零第三方依赖接入 Web Speech API，一键语音播报自查要点与呼吸操带练。

#### 3. 📊 复发风险量化评估（AJCC 第 8 版 & 列线图模型）
* **多维度临床参数测算**：
  * 涵盖手术距今时间、pTNM 分期、病理亚型、淋巴结清扫状态、驱动基因突变、胸膜侵犯（VPI）、脉管神经癌栓（LVI）、分化程度、切缘完整性、辅助治疗与吸烟史等 11 项临床指标；
  * 自动输出列线图综合评分（0~100 分）、风险分层及**预估 3 年 / 5 年无复发生存率（RFS）**；
* **病理单看懂指引与找词微提示**：
  * 内置大白话折叠指南与每道题目的“💡 报告找词”微贴士，手把手教患者对照医院报告单准确选择指标，杜绝错选乱填；
* **定制化心理释疑与科学行动策略**：
  * 针对低危、中危、高危人群分别提供专属心理释疑卡片，打破“恐癌内耗”，引导主动科学防御。

#### 4. 📅 智能随访排期与增强 CT 避坑备忘
* **动态排期生成**：根据确切手术日期与风险强度，推算未来 2 年内的 5 大复查时间窗与对应检查项目；
* **一键同步手机系统日历**：导出标准 `.ics` 日历文件，直接写入苹果 iPhone、华为、小米等系统日历并设置提前 1 天闹钟提醒；
* **胸部增强 CT 复查“行前 5 大避坑备忘”**：
  * 严格空腹 4~6 小时（防呕吐窒息）、糖尿病停服二甲双胍 48 小时（防乳酸酸中毒与肾损伤）、备齐近期血肌酐报告、带齐既往所有影像旧片逐毫米对比、检查后留观 30 分钟并饮水 2 升排毒。

#### 5. 📝 门诊就诊问诊便签与就诊长图卡片
* **门诊问题整理**：点击高频问题气泡一键加入便签，支持自主增删与一键复制；
* **📸 就诊备忘长图卡片生成器**：
  * 基于原生 HTML5 Canvas 绘制 **750px Retina 高清手机长图**；
  * 一图汇总患者随访识别码、预后评分、RFS 预测率、康复体征、问诊清单与急救预警；
  * 方便直接长按保存到相册或微信发送给主治医生与家属。

#### 6. 🩺 专科随访医生工作台（Doctor Workspace）
* **医生后台工作流**：
  * 支持按患者档案自动归纳或按单次填报流水查看；
  * 集中审阅患者术后体征、评分与问诊留言；
  * 支持高、中、低危一键筛选与全量科研数据导出为标准 CSV 表格。

### 🛠️ 技术架构与特性

| 维度 | 实现方案 | 优势 |
| :--- | :--- | :--- |
| **运行架构** | 单文件原生自内聚（HTML5 / CSS3 / ES6） | 零框架编译开销，双击或任意静态服务器即开即用 |
| **绘图引擎** | HTML5 Canvas 纯原生无依赖绘制 | 生成高清 Retina 微信就诊备忘卡，无网络跨域污染 |
| **适老交互** | 柔和微震错误提示、大字模式切换、悬浮胶囊快捷栏 | 长辈防呆交互，移动端快速直达核心功能 |
| **数据隐私** | 纯客户端沙箱存储（LocalStorage） | 无需强制实名，敏感健康信息不出患者个人设备 |
| **可扩展性** | 预留同源 RESTful 后端接口 | 具备平滑接入医院私有云与科研数据库的扩展能力 |

### 💻 本地运行说明

* **日常使用 / 患者端体验**：
  直接在电脑或手机浏览器中打开 `index.html`，即可离线使用全部功能。
* **医生后台联调（可选）**：
  若需在局域网内测试 Python 后端接口，可运行 `start.bat`（Windows）或 `start.sh`（Linux）。
